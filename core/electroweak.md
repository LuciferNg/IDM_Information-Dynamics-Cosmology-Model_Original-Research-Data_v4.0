## 1. W as Doublet

The Standard Model requires W to be an SU(2) doublet:

```
Ψ(x) = [W_u(x), W_d(x)]^T  (isospin doublet)
```

Under SU(2) local gauge transformation:

```
Ψ → Ψ' = exp(i g τ·α(x)/2) Ψ
```

Where τ = (τ₁, τ₂, τ₃) are the Pauli matrices.

## 2. Covariant Derivative

```
D_μ Ψ = (∂_μ + i g' B_μ Y + i g W_μ·τ/2) Ψ
```

Where:
- B_μ: U(1)_Y gauge field (hypercharge)
- W_μⁱ: SU(2) gauge fields (weak isospin)
- g', g: coupling constants
- Y: hypercharge

## 3. Electroweak Symmetry Breaking

The W field doublet acquires a VEV (the Higgs mechanism):

```
Ψ_0 = [0, v/√2]^T
```

This breaks SU(2)_L × U(1)_Y → U(1)_EM, giving mass to W± and Z bosons while leaving the photon massless.

## 4. Predictions

The Weinberg angle θ_W relates coupling constants:

```
sin²θ_W = g'²/(g² + g'²) ≈ 0.23
```

This is a CFAS-derived prediction — the mixing is determined by the W field's consistency allocation between isospin and hypercharge modes.
