# CFAS P4 — CP Violation from W Phase

> **Date:** 2026-07-09

---

CP violation comes from the phase of the W field in the CKM matrix generation.

In CFAS, the CKM phase δ_CP emerges from the relative phase of W modes for different generations:

```
δ_CP = arg(Σ W_u W_d* W_c W_s* W_t W_b*)
```

For the Standard Model: δ_CP ≈ 1.2 rad (from Jarlskog invariant J = 3.0 × 10⁻⁵).

In CFAS, this is a natural consequence of generational W phase evolution — each generation's W phase θ_n evolves independently, producing a net phase that breaks CP.

**Baryogenesis:** The CP-violating phase + W budget reallocation during the sync dip at z = 0.60 may produce a net baryon asymmetry. However, this is speculative — the electroweak scale baryogenesis is not derived.
