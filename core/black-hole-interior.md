## 1. Budget Limit at the Singularity

As r → 0: W budget per mode → ∞. But B = Σ|W_k|² ≤ 1.

**Resolution:** At r < r_core, the rendering cannot continue because the budget is exhausted.

The core freezes at a finite size where |W_k|² = 1 (maximum budget):

```
r_core ≈ (r_s/2) · exp(-1/ε)   where ε = sync dip amplitude ≈ 0.155
```

## 2. Hawking Temperature from Budget Leak

Hawking radiation = slow W budget leak from the core:

```
T_H = ℏc³/(8πGM) — same as standard, but modified at very small M
```

At M → M_Pl: the budget per mode approaches 1 → no more radiation → **remnant**.

## 3. Information Paradox Resolution

The core stores information in the W phase structure of its frozen modes. When the BH evaporates, the remaining core (M ~ M_Pl) contains all the information — no information loss.
