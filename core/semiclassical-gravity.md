## 1. W Field in Curved Spacetime

The W field action in curved spacetime:

```
S_W = ∫ d⁴x √(-g) [g^μν ∂_μW† ∂_νW - V(|W|²)]
```

This gives the stress-energy:

```
T_μν = ∂_μW†∂_νW + ∂_μW∂_νW† - g_μν L_W
```

## 2. Backreaction

The W field sources curvature (Einstein equations), and curvature affects W propagation (wave equation in curved spacetime):

```
□_g W + m²W = 0   (d'Alembertian in curved spacetime)
```

## 3. Scale-Dependent Budget

On curved spacetime, the consistency budget acquires a scale dependence:

```
B(μ) = B₀ · exp(-∫ dμ/μ β(μ))   (RG running of budget)
```

This connects the finite budget to the renormalization group running of all couplings.
