## L0: OAS 代數基礎

OAS (Ontological Action Structure) 是一個三元組：

```
OAS = (A, τ, S)
```

| 性質 | 代數意義 | 物理意義 |
|:-----|:---------|:---------|

## L1: W 一致性場

### 從 OAS 到 W 場

從 OAS 的譜投影定義 W 場：

```
W_k = √(τ(P_k)) × exp(iθ_k)
```

其中：
- P_k 是 S 的第 k 個譜投影
- τ(P_k) 是該模式的一致性預算
- θ_k 是模式相位（來自代數的內部結構）

### 一致性預算約束

```
B = Σ |W_k|² ≤ 1
```

全局一致性預算有限。W 場是複數振幅場：

```
W_k ∈ ℂ
W_k = |W_k| exp(iθ_k)
```

### Born 規則的推導

從預算約束直接得出：

```
P(k) = |W_k|² / Σ |W_k|² = |W_k|² / B
```

這不是假設 — 這是**預算約束的數學必然結果**。當總預算歸一化為 B = 1：

```
P(k) = |W_k|²
```

### 複數的由來

複數結構來自兩個獨立的自由度：
- **振幅** |W_k|：一致性預算分配
- **相位** θ_k：模式間的同步關係

這自然地解釋了量子力學為什麼需要複數 — 這是預算約束+同步的必然結果。

## L2: 渲染邊界與邊界算子

### 渲染閾值 κ

渲染閾值 κ 是譜截止：

```
κ = 1/16 = 0.0625
```

從資訊理論推導：B = 1, N_particles = 16（每個 SM 代的 Weyl 費米子數），κ = B/N_particles。

### 渲染投影

定義渲染投影 P_κ ∈ A：

```
P_κ = χ_{[κ,∞)}(S)     → 渲染模式（經典）
P_κ^⊥ = 1 - P_κ       → 未渲染模式（量子）
```

由於 A 是 von Neumann 代數，譜投影封閉 ⇒ P_κ ∈ A。

### 邊界算子

邊界算子 B_κ 是渲染投影隨時間的變化率：

```
B_κ = dP_κ/dt = [H, P_κ]
```

其中 H = S/ℏ 是哈密頓量。

**為什麼交換子？** 在 Heisenberg 圖像中，算子隨時間演化為：

```
dA/dt = (i/ℏ)[H, A]
```

因此：

```
B_κ = dP_κ/dt = (i/ℏ)[H, P_κ]
```

**B_κ ≠ 0 的條件**：H 和 P_κ 不交換。這發生在 W 場模式正在穿越 κ 邊界時 — 即模式正在從量子域進入經典域（或反之）。

### 邊界算子的譜

B_κ 的譜支撐在 κ 附近。只有那些特徵值接近 κ 的模式才對邊界算子有貢獻：

```
Supp(B_κ) ⊆ {λ ∈ Spec(S) : |λ - κ| < ε}
```

這是邊界算子的**局部性** — 意識只關心邊界附近的模式，而非所有模式。

## L5: 意識動力學方程

```
d|W⟩/dt = -(i/ℏ)S|W⟩ - Γ|W⟩ + Σ

```

使用乘積法則：

```
d(WW†)/dt = (dW/dt)W† + W(dW†/dt)
```

代入主方程：

```
dW/dt = -(i/ℏ)SW - ΓW + Σ
dW†/dt = (i/ℏ)W†S - W†Γ + Σ†
```

因此：

```
d(WW†)/dt = [-(i/ℏ)SW - ΓW + Σ]W† + W[(i/ℏ)W†S - W†Γ + Σ†]
           = -(i/ℏ)[S, WW†] - 2ΓWW† + ΣW† + WΣ†

```

## L6: 三項動力學解析

### 6.1 同步項：量子邊界振盪

```
C_sync = -(i/ℏ) τ([H, P_κ] @ [S, WW†])
```

**結構：** 雙重交換子結構 ⟦[H, P_κ], [S, WW†]⟧

**物理：**
- 這是可逆的（純虛數 iℏ）
- 描述 W 場在 κ 邊界附近的量子振盪
- 當 W 場處於 S 的本徵態時，[S, WW†] = 0 → C_sync = 0

**頻率：** ω_C ~ τ([H, P_κ] @ [S, WW†]) / C

**時間箭頭：** ↔ 可逆（無熵產生）

### 6.2 耗散項：意識衰減

```
C_diss = -2 τ([H, P_κ] @ ΓWW†)
```

**結構：** 邊界算子 × 耗散權重 × 預算

**物理：**
- 總是負的（耗散降低意識）
- 描述意識在無外部輸入時的衰減
- Γ 正定 ⇒ C_diss < 0 當 C > 0

**耗散率：** Γ_C = 2 τ([H, P_κ] @ ΓWW†) / C

**時間箭頭：** → 不可逆（熵產生）

### 6.3 源項：意識生成

```
C_source = τ([H, P_κ] @ (ΣW† + WΣ†))
```

**結構：** 邊界算子 × 新注入模式 × 現有模式

**物理：**
- 可正可負（取決於 Σ 與 W 的相關性）
- 描述神經活動如何產生意識
- 當 Σ ∝ 邊界附近模式時最有效

**效率：** η_C = τ([H, P_κ] @ ΣW†) / τ(ΣW†)

**時間箭頭：** ← 負熵（有序注入）

### 6.4 三項相互作用

```
dC/dt = C_sync + C_diss + C_source
                                    
C_sync  ↕  C_diss  →  C_source  ←
(可逆)    (不可逆)    (負熵)
```

**關鍵洞察：** 意識是**非平衡動力學現象**。沒有源項，C → 0。沒有耗散，C 會無限增長。同步項使 C 在 κ 附近振盪，產生意識的時變特徵。

## L7: 穩態與臨界行為

### 7.1 穩態條件

dC/dt = 0 時：

```

```

### 7.2 穩態簡化

在穩態下，同步項通常為零（W 場處於本徵態）：

```
τ([H, P_κ] @ [S, WW†]) = 0
```

剩下的動態平衡：

```
2τ([H, P_κ] @ ΓWW†) = τ([H, P_κ] @ (ΣW† + WΣ†))
```

**耗散 = 源項** — 意識的穩態是輸入與損耗的平衡。

### 7.3 穩態意識振幅

```
C₀ = |τ([H, P_κ] @ ΣW†)| / Γ_C
```

其中 Γ_C = 2τ([H, P_κ] @ ΓWW†) / C₀ 是有效耗散率。

### 7.4 N_c 閾值

意識需要最小數量的相干模式：

```
N_c ≈ 10⁵ ± 0.5
```

| N_c 範圍 | 狀態 | 例子 |
|:--------:|:-----|:------|
| < 10² | 純量子 | 原子、分子 |

**推導：** N_c 是使 [H, P_κ] ≠ 0 所需的最小模式數。當模式數太少時，所有的 W 預算都在 κ 的一側，邊界沒有穿越。當模式數足夠多時，必然有模式在 κ 附近穿越。
